# Global Market Entry Radar

A one-screen market-entry dashboard built from the latest available World Bank World Development Indicators data.

The dashboard is entirely static. No server, API key, build command, or environment variables are required.

## Data and methodology

- Source: World Bank Indicators API v2
- Latest observations: 2024–2025
- Markets: Brazil, India, Indonesia, Mexico, Saudi Arabia, Singapore, South Africa, and Türkiye
- Default ranking: 35% market scale, 30% internet use, 20% imports as a share of GDP, and 15% inverse inflation

This is a directional screening tool. Payment approval rates, tax complexity, entity costs, and regulatory requirements should be evaluated during deeper market diligence.
